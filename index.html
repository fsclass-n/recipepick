핵심 기능

RPA 할인 수집 · 자동 매칭

robots.txt 확인 → Playwright 렌더링 → BS4 파싱 → 검증 → TiDB 적재 → 냉장고·장바구니 매칭

Gemini 건강 맞춤 레시피

건강 기준·재료·알레르기·목표 열량을 조합하고 response_schema로 JSON 응답을 강제, 모델 체인 + fallback

실시간 알림 · 대시보드

마감세일 매칭 시 WebSocket 푸시와 텔레그램·디스코드·이메일 웹훅

관리자 백오피스 (RBAC)

크롤러 주기·모드 제어, pandas·Plotly 통계, 회원 권한 변경과 자기 강등 차단

상용 수준 UI/UX

공개 메인페이지, 테스트 계정 원클릭 로그인, 구글·네이버·카카오 OAuth, 다크 모드, 모바일 Drawer

자동 배포 파이프라인

main push → Render(Docker·Static)·Netlify 자동 배포, CI는 테스트·빌드·Docker 이미지 검증

PROBLEM SOLVING

실제로 겪은 문제와 해결

문제 → 원인 → 해결 → 검증 순서로 정리했습니다.

크롤링 정책과 데이터 정합성
문제
이마트 봇 차단 · 롯데ON robots 비허용, 홈플러스 할인율 99%, 두부가 ‘채소’로 분류
원인
‘50%’ 텍스트를 판매가로 파싱, ‘풀무원’의 ‘무’가 채소 키워드에 부분 일치
해결
우회 대신 수집 정책 + DEMO 표기, 셀렉터 수정 + 가격 이상치 검증, 최장 일치 분류 · 비식품 필터
검증
HTML 픽스처 단위 테스트, 실데이터 스팟 체크
AI 모델 단종 (배포 후 발견)
문제
레시피가 전부 기본 템플릿으로 대체되고 화면에는 ‘API 키 미설정’으로 잘못 표시
원인
사용하던 Gemini 모델이 신규 사용자 제공 중단(404), 대체 모델도 일시 과부하(503)
해결
모델 체인 순차 대체 + 40초 타임아웃, 실패 사유(키 없음/AI 실패) 구분 표시
검증
단위 테스트 2개 추가, 운영 API에서 실제 Gemini 생성 확인
클라우드 배포 환경
문제
Render 프런트가 localhost:8000 호출, API 무응답·크롤링 작업 중단
원인
Static Site에 API 주소 변수 누락, (가설) 512MB 무료 인스턴스 + Chromium 메모리
해결
운영 빌드 API 주소 기본값, 분석 라이브러리 지연 로드 · Chromium 저메모리 옵션 · 중단 작업 자동 정리
검증
번들 내 API 주소 확인, /api/health 200 · 운영 로그인 확인
