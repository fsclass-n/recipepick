재료 (Tech Stack)

    조리 순서 (Data Pipeline)

    1. robots.txt 확인허용 경로만 수집 · 봇 차단 사이트는 우회하지 않고 DEMO 데이터로 명시
    2. 키워드 만들기회원 장바구니 품목을 빈도순으로 검색어에 사용
    3. Playwright로 렌더링Headless Chromium · 요청 간 2초 지연 · 미디어/폰트 차단
    4. BS4로 손질하기비식품 필터 · 가격 이상치 제거 · 최장 일치 카테고리 분류
    5. TiDB에 담기마트 단위 교체 저장(단일 트랜잭션)으로 중복·만료 상품 제거
    6. 냉장고와 매칭토큰·불용어 매칭 · 24시간 중복 알림 방지 → WebSocket·웹훅
    7. Gemini로 플레이팅건강 기준·알레르기·목표 열량 프롬프트 · JSON 스키마 · 모델 체인 fallback
    Chef's note — 영양 수치는 AI 추정값이라 건강 타입별 기준과 비교해 경고만 하고, 식약처 영양성분 DB 연동을 다음 과제로 남겼습니다.

    ORDER #01RPA

    크롤링 정책과 데이터 정합성

    SOLVED
    문제
    이마트 봇 차단·롯데ON robots 비허용, 할인율 99% 데이터, 두부가 ‘채소’로 분류

    해결
    우회 대신 수집 정책 + DEMO 표기, 셀렉터 수정·가격 검증, 최장 일치·비식품 필터
    검증
    HTML 픽스처 단위 테스트
    ORDER #02AI

    Gemini 모델 단종

    SOLVED
    문제
    배포 후 레시피가 전부 템플릿으로 대체, 화면엔 ‘API 키 미설정’으로 잘못 표시
    원인
    사용 모델이 신규 사용자 제공 중단(404), 대체 모델도 일시 과부하(503)
    해결
    모델 체인 순차 대체 · 40초 타임아웃 · 실패 사유 구분 표시
    검증

    ORDER #03DEVOPS

    클라우드 배포 환경

    SOLVED
    문제
