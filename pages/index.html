RecipePick

대형마트 마감세일·할인가 식재료를 RPA(Playwright)로 수집하고, 냉장고 재고와 건강 상태(당뇨·다이어트·고혈압)를 분석해 Google Gemini가 맞춤형 건강 레시피를 창작하는 냉장고 파먹기 짠테크 플랫폼

서비스 바로가기 Staging (Netlify) API Docs GitHub

RPA 할인 수집

Playwright Headless Chromium + BeautifulSoup으로 마트 할인 상품을 주기적으로 수집하고 robots.txt 정책을 준수합니다.

냉장고 파먹기

냉장고 재고·장바구니를 관리하고 할인 중인 재료를 자동 하이라이트, 마트별 최저가 장바구니 맵을 제공합니다.

Gemini AI 레시피

할인 재료 + 냉장고 재료 + 건강 상태를 프롬프트로 조합해 조리법·영양 성분·대체 식재료를 생성합니다.

실시간 알림

마감세일 매칭 시 WebSocket 푸시와 텔레그램·디스코드·이메일 웹훅으로 즉시 알려드립니다.
